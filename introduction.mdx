**Geek Hub** es la API gateway de modelos de inteligencia artificial hecha para México y Latinoamérica.

Una sola llave te abre el **catálogo first-party** (decenas de modelos) y, si hace falta, **cobertura extendida** del long-tail con el mismo formato `maker/slug`:

## Estructura del API

Todos los endpoints son OpenAI-compatible donde aplica:

```
POST /v1/chat/completions       Chat con cualquier modelo
POST /v1/images/generations     Generación de imágenes
POST /v1/videos/generations     Generación de video (async)
GET  /v1/videos/{id}            Estado de un job de video
POST /v1/audio/speech           Text-to-speech
POST /v1/embeddings             Embeddings
GET  /v1/generation?id=         Audit de un request (costo, modelo, latencia)
GET  /v1/models                 Catálogo (first-party + cobertura extendida)
GET  /v1/credits                Saldo de la org
GET  /health                    Health check (público)
```

https://api.geekhub.mx
