El endpoint `POST /v1/images/generations` es compatible con la API de OpenAI Images. Cambias el `model` y eliges de nuestro catálogo.

## ¿Qué modelos puedo usar?

| ID | Provider | Precio proveedor | Notas |
|----|----------|------------------|-------|
| `openai/gpt-image-1` | OpenAI | $0.19/img | Alta calidad |
| `google/gemini-2.5-flash-image` | Google | $0.039/img | Rápido, buen texto |
| `fal/flux-1.1-pro` | fal.ai | $0.04/img | Balance open-weight |
| `fal/flux-1.1-pro-ultra` | fal.ai | $0.06/img | Flux 4K |
| `fal/recraft-v3` | fal.ai | $0.04/img | Brand / tipografía |
| `fal/ideogram-v2` | fal.ai | $0.08/img | Tipografía profesional |
| `fal/sd-3.5-large` | fal.ai | $0.065/img | SD 3.5 Large |

Cobro al cliente ≈ ×1.09 — [Facturación](/concepts/billing).

## Storage propio

Cada imagen se sube a Supabase Storage de Geek Hub con URLs persistentes (org + request UUID).

```bash
curl -O https://supabase.geekhub.mx/storage/v1/object/public/generated-images/.../0.png
```
