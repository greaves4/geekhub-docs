Video toma de segundos a minutos. Flujo **asíncrono**:

```
POST /v1/videos/generations    → Crea job, regresa job_id
GET  /v1/videos/{job_id}        → Estado + URL si completed
```

## Patrón de uso

```python
import time
import httpx

headers = {"Authorization": "Bearer ghub_sk_live_xxx"}
base = "https://api.geekhub.mx/v1"

job = httpx.post(f"{base}/videos/generations", headers=headers, json={
    "model": "fal/hailuo-02",
    "prompt": "Un colibrí bebiendo de una flor de cempasúchil al amanecer",
    "duration": 5,
}).json()
job_id = job["id"]

while True:
    status = httpx.get(f"{base}/videos/{job_id}", headers=headers).json()
    if status["status"] == "completed":
        print(status["video_url"])
        break
    if status["status"] == "failed":
        raise RuntimeError(status.get("error"))
    time.sleep(15)
```

## Estados

| Status | Significado |
|--------|-------------|
| `pending` | Creado, aún no enviado al provider |
| `processing` | Renderizando |
| `completed` | Listo; `video_url` en storage |
| `failed` | Error; no se cobra |

Solo en `completed` cobramos (`duración × $/seg` con [Facturación](/concepts/billing)).
