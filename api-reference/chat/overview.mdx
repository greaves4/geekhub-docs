El endpoint `POST /v1/chat/completions` es **100% compatible con el SDK oficial de OpenAI** para Python y Node.js. Solo cambias `base_url` y `api_key`.

## ¿Qué modelos puedo usar?

~31 modelos first-party + [cobertura extendida](/concepts/openrouter). Ejemplos:

```
anthropic/claude-sonnet-4-6
anthropic/claude-haiku-4-5
google/gemini-2.5-flash
google/gemini-3.1-flash-lite
openai/gpt-5
openai/gpt-5.4-mini
deepseek/deepseek-v4-flash
moonshot/kimi-k2.7-code
xai/grok-4.3
```

Lista completa y precios: [Modelos chat](/models/chat) o `GET /v1/models`.

## Funcionalidades

| Feature | Soportado |
|---------|-----------|
| Mensajes `system`, `user`, `assistant` | ✅ |
| Streaming SSE (`stream: true`) | ✅ |
| `temperature`, `top_p`, `max_tokens`, `stop` | ✅ |
| Multi-turn | ✅ |
| Fallbacks / `model: "auto"` | ✅ — [Fallbacks](/concepts/fallbacks) |
| ZDR / guardrails | ✅ |
| Function calling / vision / JSON mode | Depende del proveedor (pasa params OpenAI-compat) |

## Routing

Detrás de cada model id first-party llamamos al maker. Long-tail usa la misma API con la marca del maker en `owned_by`.
