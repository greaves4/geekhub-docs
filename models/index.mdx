## Naming

Formato `<provider>/<model-slug>`:

- `anthropic/claude-sonnet-4-6`
- `openai/gpt-5`
- `google/gemini-2.5-flash`
- `fal/flux-1.1-pro`
- `xai/grok-4.3`

## API live

Fuente de verdad:

```bash
curl https://api.geekhub.mx/v1/models \
  -H "Authorization: Bearer ghub_sk_live_xxx"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "anthropic/claude-sonnet-4-6",
      "object": "model",
      "kind": "chat",
      "owned_by": "anthropic",
      "context_length": 200000,
      "pricing": {
        "input_per_1m_usd": 3,
        "output_per_1m_usd": 15
      }
    }
  ]
}
```

Las tablas estáticas en estas docs son guía; si hay diferencia, **gana** `GET /v1/models`.

## Pricing

Los precios listados son **USD del proveedor**. El cobro al cliente:

```
sell_usd ≈ provider_usd × 1.09
         = provider_usd × (1.05 / (1 − 1.05 × carga_stripe))
```

Detalle en [Facturación](/concepts/billing). El ledger convierte a MXN con FX fijo (hoy 20).
