## Cuándo usar cada uno

### Crítico / presupuesto alto
**Claude Opus** o **GPT-5.x** top de la familia.

### Producción a escala
**Claude Sonnet 4.6 / 5** o **Gemini 2.5 Flash**.

### Alto volumen / barato
**DeepSeek V4 Flash**, **Gemini Flash Lite**, **GPT-5.6 Luna**.

### Código
**Kimi K2.7 Code** o **Claude Sonnet**.

### Context largo
**Gemini 2.5/3.x Pro** (hasta 2M) o **GPT-4.1 mini** (1M).

## Failover

Misma API → lista de modelos o `model: "auto"`. Ver [Fallbacks](/concepts/fallbacks).
