## 1 · Crea tu cuenta

Ve a [app.geekhub.mx/signup](https://app.geekhub.mx/signup) y regístrate. Sin tarjeta, sin compromisos.

## 2 · Genera tu API key

En el dashboard, ve a **API Keys → Nueva API key**.

<Warning>
  La key se muestra **una sola vez**. Cópiala a tu password manager antes de cerrar el modal.
</Warning>

El formato es:

```
ghub_sk_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

## 3 · Tu primera llamada

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.geekhub.mx/v1",
    api_key="ghub_sk_live_TU_KEY",
)

response = client.chat.completions.create(
    model="anthropic/claude-haiku-4-5",
    messages=[{"role": "user", "content": "Hola, en una sola línea"}],
)

print(response.choices[0].message.content)
```

```javascript Node.js
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.geekhub.mx/v1",
  apiKey: "ghub_sk_live_TU_KEY",
});

const response = await client.chat.completions.create({
  model: "anthropic/claude-haiku-4-5",
  messages: [{ role: "user", content: "Hola, en una sola línea" }],
});

console.log(response.choices[0].message.content);
```

```bash curl
curl -X POST https://api.geekhub.mx/v1/chat/completions \
  -H "Authorization: Bearer ghub_sk_live_TU_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-haiku-4-5",
    "messages": [{"role":"user","content":"Hola, en una sola línea"}]
  }'
```

</CodeGroup>

## 4 · Cambia de modelo

Solo cambia el campo `model`. **El mismo SDK** funciona con todos:

```python
model="openai/gpt-5"
model="google/gemini-2.5-flash"
model="deepseek/deepseek-v4-flash"
model="moonshot/kimi-k2.7-code"
model="xai/grok-4.3"
```

Ver el [catálogo](/models). Para modelos fuera del first-party, ver [cobertura extendida](/concepts/openrouter).

## 5 · Cuando se acabe el saldo

Recarga en USD desde [app.geekhub.mx/dashboard/billing/recharge](https://app.geekhub.mx/dashboard/billing/recharge). Stripe cobra la tarjeta; el crédito entra 1:1 en USD. Si tienes datos fiscales, se emite **CFDI 4.0**.
