## Modelo de cobro

**Pay-as-you-go**, sin mínimos ni suscripción. Solo pagas lo que consumes.

El precio de venta (USD) parte del costo del proveedor y mete Stripe **dentro** del costo cargado, para que el margen no se lo coma la pasarela:

```
carga_stripe = 2.9% + ($0.30 / top-up típico $50)   ≈ 3.5%
sell_usd     = provider_usd × (1.05 / (1 − 1.05 × carga_stripe))
             ≈ provider_usd × 1.09
```

- **+5% de utilidad bruta** sobre (proveedor + carga Stripe), no solo sobre el proveedor
- El ledger interno guarda el cobro en **MXN** con FX fijo (hoy **20 MXN/USD**)
- El dashboard y `GET /v1/credits` te muestran el saldo en **USD** (equivalente)
- **Sin cargo** en 4xx / 5xx

### Ejemplo (chat)

`anthropic/claude-haiku-4-5` · 100 input + 500 output:

```
Provider:  (100 × $1 / 1M) + (500 × $5 / 1M) = $0.0026 USD
Sell ≈ $0.0026 × 1.09 ≈ $0.0028 USD  (≈ $0.057 MXN al FX 20)
```

Los precios en [Modelos](/models) son **USD del proveedor**. El gateway aplica la fórmula de arriba al cobrar.

## Recargas y saldo

Recargas en **USD** (1:1 de crédito) desde [Facturación → Recargar](https://app.geekhub.mx/dashboard/billing/recharge):

- Tarjeta (Stripe)
- _Próximo:_ OXXO, SPEI, PayPal

Cada llamada exitosa descuenta el costo del saldo de forma atómica. Con saldo ≤ 0:

```json
HTTP 402 Payment Required

{
  "error": {
    "message": "Insufficient balance. Recharge at https://app.geekhub.mx/dashboard/billing.",
    "type": "insufficient_balance",
    "code": "insufficient_balance"
  }
}
```

## CFDI 4.0

Cada recarga genera un **CFDI 4.0** timbrado por el SAT cuando Stripe confirma el cobro. Configura RFC / razón social / régimen en [Ajustes → Fiscal](https://app.geekhub.mx/dashboard/settings).

Sin datos fiscales, el CFDI sale a **Público en General** (`XAXX010101000`, Uso `S01`). Las recargas ya emitidas no se re-timbran; las siguientes usan tus datos nuevos.

En [Facturación](https://app.geekhub.mx/dashboard/billing) puedes ver folio, UUID SAT, estado y descargar XML / recibo. El monto fiscal del CFDI va en MXN (subtotal + IVA según el cobro Stripe).
